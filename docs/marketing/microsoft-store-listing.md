# Microsoft Store 上架文案

## 产品名称

Clipboard

## 短描述

本地优先的 Windows 剪贴板历史工具，支持文字、图片、搜索、分类和多格式复制。

## 完整描述

Clipboard 帮你找回复制过的文字和图片，并把常用内容整理成真正可用的工作区。

主要功能：

- 保存文字、富文本和图片历史
- 搜索、分类、置顶和保留时间设置
- 自由选取记录中的部分文字
- 复制为纯文本、Markdown、HTML 或单行文本
- 自定义全局快捷键
- 本地加密密码库
- 无需账户，当前版本没有云同步

Clipboard 适合程序员、写作者、学生、运营和经常整理资料的 Windows 用户。需要时按快捷键打开，找到内容，继续工作。
