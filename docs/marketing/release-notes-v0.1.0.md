# Clipboard 0.1.0

Clipboard 是一款本地优先的 Windows 剪贴板工具。

## 功能

- 文字、富文本和图片历史
- 搜索、分类、置顶与保留时间
- 自由选取记录中的文字
- 复制为纯文本、Markdown、HTML 或单行文本
- 自定义全局快捷键
- 本地加密密码库
