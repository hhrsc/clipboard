# Clipboard 首轮宣传文案

## 产品短介绍

Clipboard 是一款本地优先的 Windows 剪贴板工具。它保存文字和图片历史，支持搜索、分类、置顶和全局快捷键。你还可以自由选取一段文字，再复制为纯文本、Markdown、HTML 或单行文本。

官网：https://hhrsc.github.io/website

## V2EX 首发

### 标题

[分享创造] 我做了一个本地优先的 Windows 剪贴板工具，支持自由选取和多格式复制

### 正文

我经常遇到两个小麻烦：刚复制过的内容被下一次复制覆盖了；从网页或文档里复制一段文字时，还要手动清理格式。

所以我做了 Clipboard，一款本地优先的 Windows 剪贴板工具。

目前支持：

- 保存文字、富文本和图片历史
- 搜索、分类、置顶和保留时间设置
- 在详情里自由选取需要的文字
- 复制为纯文本、Markdown、HTML 或单行文本
- 自定义全局快捷键
- 本地加密密码库
- 当前版本不需要账户，也没有云同步

安装包面向 64 位 Windows。官网公开了版本页、源码入口和 SHA-256 校验值：

https://hhrsc.github.io/website

它还是早期版本。我更想知道大家真实工作流里的问题：你通常复制什么内容，Win+V 最让你不顺手的地方是什么？

## 抖音和视频号脚本

### 脚本 1：复制被覆盖

时长：18 秒

- 0-3 秒：画面显示“刚复制的内容，又被下一次复制覆盖了？”
- 3-8 秒：按快捷键打开 Clipboard，搜索刚才的文字
- 8-14 秒：选中记录并复制回来
- 14-18 秒：字幕“Windows 本地剪贴板历史，官网可下载”

口播：刚复制的内容被覆盖，不用回原页面重找。按一下快捷键，搜索，复制回来。Clipboard，数据保存在本机。

### 脚本 2：只复制其中一段

时长：20 秒

- 0-4 秒：展示一大段网页文字，字幕“我只想要中间这两句”
- 4-10 秒：在 Clipboard 详情中拖动选择文字
- 10-16 秒：点击复制为 Markdown
- 16-20 秒：粘贴到编辑器，展示干净结果

口播：一整段文字，只要其中几句。直接选中，再复制为 Markdown、HTML 或纯文本，不用来回清格式。

### 脚本 3：图片历史

时长：16 秒

- 0-4 秒：快速复制三张图片
- 4-10 秒：打开图片历史并筛选
- 10-16 秒：预览并重新复制目标图片

口播：复制过的图片不该一次性消失。按时间浏览，找到它，再复制回去。

### 脚本 4：本地优先

时长：18 秒

- 0-5 秒：字幕“剪贴板里可能有地址、代码、账号信息”
- 5-12 秒：展示本地保存、无账户、无云同步的官网说明
- 12-18 秒：展示应用密码库锁定状态

口播：剪贴板里不只有无关紧要的文字。Clipboard 当前不需要账户，也没有云同步，历史和密码库保存在本机。

## 常见评论回复

### 和 Win+V 有什么区别？

Win+V 适合快速找回最近内容。Clipboard 进一步提供搜索、分类、置顶、图片管理、保留时间和多格式复制，更适合记录较多的工作流。

### 会上传剪贴板吗？

当前版本没有账户和云同步，剪贴板历史与密码库保存在本机。官网提供完整隐私说明。

### 安装时 Windows 提示风险怎么办？

这是独立开发者新应用常见的 SmartScreen 信誉问题。请只从官网或 GitHub Releases 下载，并核对官网公布的 SHA-256。后续会推进代码签名和 Microsoft Store 上架。

### 支持 macOS 吗？

当前只提供 64 位 Windows 版本。其他平台尚无确定计划。

### 免费吗？

当前公开下载版本可免费使用。未来定价如有变化，会在版本说明中提前写清楚。
